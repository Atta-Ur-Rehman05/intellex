# Intellex

> Your AI-Powered Knowledge Workspace

Intellex is an AI-powered knowledge management platform that allows users and teams to upload, organize, search, and interact with their documents using Retrieval-Augmented Generation (RAG).

## Project Status

🚧 Under active development

## Architecture

Intellex is being developed as a modular monolith with:

- Vite + React frontend
- FastAPI backend
- PostgreSQL
- Redis
- Qdrant
- Object storage
- Background workers
- LLM integration
